# PhishGuard 🔐

PhishGuard is a simple phishing URL detection tool built with Flask.
It analyzes URLs using common phishing indicators and assigns a risk score.

## Features
- URL length analysis
- IP-based domain detection
- Suspicious keyword detection
- Subdomain abuse detection
- Risk scoring (Low / Medium / High)
- Light & Dark mode UI

## Tech Stack
- Python
- Flask
- HTML / CSS / JavaScript

## How to Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/phishguard.git
cd phishguard
pip install -r requirements.txt
python app.py
