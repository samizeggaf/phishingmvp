# PhishGuard 🛡️

A phishing URL detection tool built with Python and Flask.

## What it does
PhishGuard analyzes URLs using heuristic indicators and assigns a risk score to detect potential phishing attempts. It checks for suspicious patterns including keyword analysis, URL length, domain structure, and known phishing signals.

## Tech Stack
- Python
- Flask
- HTML/CSS/JavaScript

## How to run

1. Clone the repository
git clone https://github.com/samizeggaf/PhishGuard.git

2. Install dependencies
pip install -r requirements.txt

3. Run the app
python app.py

4. Open your browser at http://localhost:5000

## Features
- URL heuristic analysis
- Risk score assignment
- Simple and fast web interface
