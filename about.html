About PhishGuard

PhishGuard is a simple phishing detection MVP built with Flask. It analyzes URLs using common phishing indicators such as:

  • Suspicious keywords
  • IP-based domains
  • Too many subdomains
  • Long URLs or domains
  • Usage of '@' redirection

This is the first version. Advanced AI/ML detection will be added later.
